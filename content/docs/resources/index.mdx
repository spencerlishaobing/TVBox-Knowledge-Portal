# 资源治理

资源不再以“收藏一堆链接”为目标，而是维护可验证资产：

| 字段 | 说明 |
| --- | --- |
| 标识 | 稳定 ID，名称变化不影响历史 |
| 类型 | 多仓、单仓、Spider、直播、EPG、解析器、网盘 |
| 来源 | 获取渠道与维护责任 |
| 状态 | 有效、降级、失效、待复核 |
| 最后检查 | 带时区的检查时间 |
| 延迟 | DNS、连接、首字节和完整响应 |
| 失败原因 | HTTP、TLS、超时、格式、鉴权、业务错误 |
| 证据 | 检查脚本版本和结果摘要 |

失效资源不会立即删除：先标为失效并保留历史，确认长期不可恢复后再从默认配置移除。
