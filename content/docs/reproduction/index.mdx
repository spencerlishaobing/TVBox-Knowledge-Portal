# 影视仓复刻总览

影视仓复刻基于 TVBoxOS 的配置协议与业务语义，目标平台是 Windows PC，不照搬遥控器焦点模型和 Android UI。

## 核心范围

- 首页、分类筛选、搜索、详情、选集和播放。
- 多仓/单仓配置、二维码配置、接口切换与错误诊断。
- 普通影视站、JAR/Python/JavaScript Spider、网盘资源和解析器。
- 直播分组、频道、线路、EPG、回看和收藏。
- 视频字幕、倍速、音轨、进度、画面比例、4K/8K 硬解与真全屏。
- 直播与点播能力隔离，避免字幕等点播功能出现在直播界面。

## 产品原则

PC 使用鼠标、键盘和窗口模型；页面采用路由切换，详情、播放器和设置不以多层遮罩无限覆盖。临时操作使用弹窗，核心任务使用独立页面或明确返回路径。
