# 可重复破解流程

```text
多仓入口 → 解码仓库列表 → 定位饭太硬单仓 → 提取 spider 声明
         → 下载并校验原件 → 判断 class/DEX/guard → 转换与反编译
         → 生成调用链和接口差异 → 翻译桌面实现 → 白盒与播放验收
```

## 强制输出

- 原始文件及 MD5/SHA-256。
- 配置解析报告和重定向链。
- Java 文件、字节码兜底与反编译错误摘要。
- 新旧版本类、方法、常量、域名和请求参数差异。
- 适配状态、失败原因与可视化验收证据。
