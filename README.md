# TVBox Knowledge Portal

TVBox、影视仓、饭太硬逆向与接口资源治理的公开技术门户。网站使用 MkDocs Material，通过 GitHub Actions 部署到 GitHub Pages。

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\mkdocs serve
```

完整原始配置、JAR/DEX、未脱敏接口和逆向证据不进入本公开仓库，统一保存在私有 `TVBox-FanTaiYing-KnowledgeBase`。
