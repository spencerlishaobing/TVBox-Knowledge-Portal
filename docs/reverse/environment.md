# 环境与工具链

当前可重复环境基线：

| 工具 | 固定版本 | 用途 |
| --- | --- | --- |
| Windows | Windows 11 x64 | 主分析与产品构建环境 |
| OpenJDK | 21.0.2 LTS | Java 编译、`javap`、CFR |
| Python | 3.13.9 | 配置同步、报告和验证脚本 |
| CFR | 0.152 | Java 反编译主视图 |
| dex2jar | 2.4 | DEX 转 JVM class/JAR |
| Rust | 1.99.0 | SimpleTools/Tauri 后端 |
| Node.js | 24.11.1 | 前端与自动化测试 |

完整工具哈希、下载来源和命令参数保存在私有资料库，以免公开资料中包含原始逆向文件地址。
