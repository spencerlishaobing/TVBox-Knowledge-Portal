# 进度与缺口

## 已完成基线

- TVBox 核心导航、首页、搜索、详情、播放、直播、收藏、历史与设置。
- libmpv、JVM、Python 和常用本地 Spider 打包。
- 饭太硬配置同步、JAR 归档与完整旧版反编译基线。
- 玩偶、WoGG 等重点站点的本地适配探索。

## 当前重点

1. 以影视仓 APP 的用户流程重新核对 TVBoxOS 到 PC 的功能映射。
2. 网盘详情、封面、选集名称、二维码登录和真实播放链闭环。
3. 直播源失效检测、线路自动降级与 EPG 可用性。
4. 点播/直播播放器能力彻底解耦。
5. 4K/8K、60fps、硬解、HDR 和真全屏的媒体信息证据化验收。
